# 製本（フォトブック）設計

出力は PDF。印刷所に投げればそのまま本になる形を目指す。

## 前提としない方針

「日本らしさ」を桜・和柄・毛筆フォントのような**装飾**で出さない。それをやると
日本人ユーザーには外国人向けの土産物に見えて使えなくなる。
日本らしさは**構造**で出す。具体的には次の4つ。

| 借りる型 | 何が日本的か | 日本人にとって | 訪日客にとって |
|---|---|---|---|
| 御朱印帳 | 参拝の記録を1ページずつ集める本 | 馴染みのある実用品 | 記念になる工芸品 |
| 蛇腹（折本） | ページをまたいで絵が続く | 見慣れた形 | 珍しい造本 |
| 道中記 | 宿場・里程を淡々と記す旅日記 | ただの行程表 | 江戸の旅の様式 |
| 間 | 余白を埋めない | 心地よい | 洗練 |

装飾ではなく型なので、どちらの読者にも「自分の本」として通用する。

## アルゴリズム

### 1. 章立て — 都道府県で切る（日付でも地点でもなく）

```
chapters = []
for stop in stops(順路):
    if chapters and chapters[-1].pref == stop.pref:
        chapters[-1].stops.append(stop)      # 連続する同一県はまとめる
    else:
        chapters.append(Chapter(pref=stop.pref, stops=[stop]))
```

地点ごとに1ページ割ると単調な写真集になる。県で切ると
**1章＝1御朱印**が自動的に成立し、本の背骨が御朱印帳になる。
離れて再訪した県は別章にし、章扉に「再訪」と入れる。

### 2. ページ配分 — 平方根で割る

```
weight(chapter) = sqrt(写真枚数) * (1 + 0.15 * 滞在日数)
pages(chapter)  = clamp(round(総ページ数 * weight / Σweight), 2, 8)
```

線形に配分すると、写真を100枚撮った1箇所が本を食い潰す。
平方根にすることで「たくさん撮った場所は少し厚い」程度に収まる。

### 3. 写真選定 — 全部は載せない

各写真に得点をつけ、章の割当枠だけ採る。

```
score = 0.30 * 解像度スコア
      + 0.25 * (ユーザーが1枚目に置いたか)     # 自分で選んだ表紙は強い
      + 0.20 * 構図スコア（極端な縦横比を減点）
      + 0.15 * 時間的な散らばり               # 直前に採った1枚と近い時刻なら減点
      + 0.10 * 地点の多様性                    # 同じ地点ばかりにならないように
```

**時間的な散らばり**が肝。連写した似た10枚から1枚だけ採るためのもので、
これが無いと「ただ画像を並べた本」になる。

### 4. 割付 — 写真の形からテンプレートを選ぶ

採った写真の縦横比の並びを見て、下の型から選ぶ。

| 写真 | 型 |
|---|---|
| 横1枚 | 見開き全面（裁ち落とし） |
| 縦1枚 | 片ページに小さく置き、余白に本文（間） |
| 縦2枚 | 向かい合わせ |
| 横1＋縦2 | 主従のある非対称組み |
| 4枚以上 | 主1枚＋従3枚。**均等な2×2は使わない** |

均等グリッドを禁じ手にしているのは、それが「並べただけ」に見える唯一の型だから。

### 5. 通し帯（蛇腹の代わり）

全ページの下端に、旅の全行程を1本の細い線として引く。
現在のページの地点だけ点を打つ。ページをめくると点が進み、線は途切れない。

```
x(stop_i) = 左マージン + (i / (N-1)) * 版面幅
```

地図の線ではなく**進捗の線**。GPSを持つ旅アプリにしか作れないページ要素で、
折本を開いたときの連続性を綴じ本で再現する。

### 6. 固定ページ

| # | ページ | 内容 |
|---|---|---|
| 1 | 表紙 | 主題写真1枚、題（縦書き可）、年月 |
| 2-3 | 扉 | 日本全図に今回の行程。地名は最小限 |
| 4-5 | 行程表 | 日付・地名（漢字/ローマ字）・移動手段・距離。道中記の様式 |
| — | 章扉 | 県名（漢字＋ローマ字）、御朱印、滞在日、MATCHAの一行 |
| — | 写真面 | §4 の型 |
| 末 | 奥付 | 総距離・日数・県数・日本の何%・手段の内訳・作成日 |

奥付は日本の本なら必ずある頁で、日本人には自然、訪日客には様式として面白い。

### 7. 季節の印

日付から二十四節気を引き、章扉に小さく添える（例: `清明 · Qingming, early April`）。
日本人には季語として自然に読め、訪日客には土地と時期の関係が伝わる。
グラフィックにはせず、1行の文字として置く。

### 8. 台割の丸め

印刷は4の倍数（折）で綴じる。計画後に端数が出たら、
写真1枚と大きな余白だけの「息継ぎページ」を足すか、
最も点の低い写真面を1枚落として調整する。

```
while total_pages % 4 != 0:
    add_breather() or drop_lowest_scoring_photo_page()
```

### 9. 二言語を既定にする

地名は常に **漢字 + romaji** を併記。本文はユーザーが書いた言語のまま。
訪日客向けの説明文を足したり、日本人向けに漢字だけにしたりしない。
併記が、両方の読者が同じ本を使える最小の条件になる。
