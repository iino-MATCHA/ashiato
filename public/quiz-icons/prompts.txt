HOW TO USE
  1. Copy one PROMPT block below and give it to the image AI.
  2. Save the result under the FILE name shown for that block.
  3. Put the files in  public/quiz-icons/  in this repository.

FORMAT
  SVG preferred (one file covers every screen density).
  If the tool only makes raster: transparent PNG, 1024x1024. Do NOT use webp.

REJECT AND RETRY IF
  - any red / vermilion appears (that colour is reserved for goshuin seals)
  - more than one green element
  - lines are thick/filled, or the drawing is busy in the middle
    (it must still read at 26 x 26 pixels)
